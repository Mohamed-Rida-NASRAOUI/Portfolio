# Portfolio – Mohamed-Rida Nasraoui

Site vitrine personnel et professionnel, bilingue (français / anglais), présentant mon parcours en Bachelor Informatique à l’ECE Bordeaux, mon stage chez Orange Business, mes projets et mes compétences.

## Fonctionnalités
- Design sombre, responsive (ordinateur, tablette, téléphone)
- Bascule FR / EN
- Menu mobile accessible au clavier
- Animations discrètes, désactivées si l’utilisateur demande de réduire les animations (`prefers-reduced-motion`)

## Technologies
HTML5 · CSS3 · JavaScript natif · Git / GitHub · GitHub Pages. Aucune dépendance externe, aucune donnée collectée.

## Structure
- `index.html` : contenu
- `css/style.css` : design et animations
- `js/script.js` : menu, traduction et interactions
- `assets/` : images et CV

## Lancer en local
Ouvrir `index.html` dans un navigateur, ou utiliser l’extension Live Server de VS Code.
